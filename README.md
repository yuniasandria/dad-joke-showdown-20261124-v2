Entry for the [Dad Joke Showdown](https://make.fun/c/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun.

`main.py` (pure Python stdlib) writes one dad joke — at most 200 characters — to `/output/entry.txt`:

> I told Dad the elevator stopped working. He sighed, 'Well, that's just another level of disappointment.'

Run it with `python3 main.py` (honors `$MAKEFUN_OUTPUT_DIR` / `$OUTPUT_DIR`, default `/output`).
